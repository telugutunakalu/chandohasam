# yathi_compact.md — parsable Telugu yati rule table

Distilled from `yathi.md` (పద్యవిద్య ch. 6, §6.0–§6.79, all 20 parts). Human-readable
detail per rule: `rules/*.md` (same ids). Companion of `../prasa_rules.yaml`.

## Line grammar

- Every rule is ONE line: `- id=<ID> | key=value | key=value ...`
- Field separator ` | ` (space, bar, space). Values never contain `|`.
- Keys (in this order; optional keys may be absent):
  `id` `kind` `status` `src` `name` `when` `match` `scope` `note` `ref`
- `id` = `YATI-<FAMILY>-<NN>` or `YATI-<FAMILY>-<NN>.<k>` (sub-rule, k may have two digits). Families:
  POS position/inventory, MOD signs at the junction, SV svara, VY vyañjana,
  SY saṁyukta, SP special vyañjana, UB ubhaya, PY prāsa-yati, DL derived/late,
  RJ rejected, EP engine procedure.
- `kind` ∈ {position, modifier, class, bheda, vidhana, ubhaya, prasa, reject, procedure, info}
  (bheda = WHICH sounds pair; vidhana = HOW/WHERE the test is applied; ubhaya = vidhana that
  opens both a vowel track and a consonant track).
- `status` ∈ {canonical, canonical_subtype, mandatory, accepted_relaxation, orthographic_relaxation,
  deprecated, forbidden, informational} — same vocabulary and profile semantics as prasa_rules.yaml
  (strict ⊂ relaxed ⊂ historical; see YATI-EP-09).
- `match` notation: `A <-> B` bidirectional pairing; `{a,b}` set; `C` any consonant; `V` any vowel;
  `x -> y` "x is evaluated as y"; `svara:` / `hal:` the two tracks of an ubhaya node;
  `!` = forbidden pairing. Vowel classes: `A={అ,ఆ,ఐ,ఔ}` `I={ఇ,ఈ,ఋ,ౠ,ఎ,ఏ,ఌ}` `U={ఉ,ఊ,ఒ,ఓ}`.
  Unless a rule says otherwise, every consonant pairing also requires the two vowels to be in the same class (YATI-SV-01.1).
- `src` = book section(s). `ref` = detailed file. `=Yn.m` in `note` = same rule in yathi1.md / yathi2.md.

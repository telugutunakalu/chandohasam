# 05 — Special consonant yatis [6.31 – 6.38]

Source: `../yathi.md` parts 8–10.

## A. తద్భవవ్యాజ యతి [6.31 – 6.31.1]

- **YATI-SP-01** [6.31] **జ్ఞ ↔ {న, ణ}** as a whole unit (tadbhava sound law: యజ్ఞము→జన్నము, విజ్ఞానము→విన్నాణము, ఆజ్ఞ→ఆన; ణ via న–ణ). This is *in addition to* saṁyukta decomposition of జ్ఞ into జ or ఞ. Attested జ్ఞా↔న, జ్ఞా↔నా, జ్ఞ↔ని, ని↔జ్ఞీ, జ్ఞే↔నె, జ్ఞా↔ణ. status: canonical (kind: bhēda).

## B. విశేష యతి [6.32 – 6.32.2]

- **YATI-SP-02** [6.32] **జ్ఞ ↔ {క ఖ గ ఘ}** (vernacular జ్ఞ → గ/గ్య: జ్ఞాపకము→గేపకము, ప్రజ్ఞ→పగ్గియ, సంజ్ఞ→సైగ; then vargaja). Tikkana Udyōga 4-255 జ్ఞా↔కా is authentic (the "ప్రజనితము" emendation is a corruption). Attested క↔జ్ఞ, కా↔జ్ఞ, జ్ఞా↔క/కా/ఖ/గ/ఘ. status: canonical (kind: bhēda).

## C. మవర్ణ యతి / మా వడి [6.33 – 6.33.3]

- **YATI-SP-03** [6.33] **ం + {య ర ల వ శ ష స హ} ↔ మ** (Pāṇini 8-3-23 మోఽనుస్వారః: a word-final మ్ becomes anusvāra before any consonant; before semivowels/spirants it resonates as మ్, so the cluster is treated as containing మ under the saṁyukta principle). Appakavi 3-76 covers all eight: మ↔ంయ, ంర, ంల, ంవ, ంశ, ంష, ంస, ంహ; also మై↔ంహ, మా↔ంశ, మ↔ంసా, మీ↔ంహి. status: canonical (kind: bhēda).

## D. అంత్యోష్మసంధి యతి / వికల్పయతి (Anantudu) [6.34 – 6.34.3]

- **YATI-SP-04** [6.34] Unvoiced stop {క్ ట్ త్ ప్} + **హ** across a Sanskrit compound boundary → voiced stop + optional assimilation to the 4th stop (Pāṇini 8-4-62 ఝయో హోఽన్యతరస్యామ్): వాక్+హరి → వాగ్ఘరి / వాగ్హరి; జగత్+హిత → జగద్ధిత; ఉద్+హత → ఉద్ధత; కకుప్+హస్తి → కకుబ్భస్తి. At that cluster the poet may:
  - **Option A** surface stop scansion (ద్ధ → ద/ధ vargaja; గ్ఘ → క/గ/ఘ; డ్ఢ → డ/ఢ; బ్భ → బ/భ …);
  - **Option B** the underlying **హ** — hence also అ↔హ (sarasa-3: ద్ధ[హ]↔అ/ఆ/ఏ), య↔హ (ṛju: ద్ధ[హ]↔యా), హ↔హ (ద్ధా[హా]↔హ), and even ఋ↔ద్ధ్రీ[హ్రీ].
  Appakavi 3-115 shows both options in each line. status: canonical (kind: vidhāna).

## E. వికల్ప యతి / యుక్త వికల్పయతి [6.35 – 6.35.6]

- **YATI-SP-05** [6.35] Unvoiced stop {క్ చ్ ట్ త్ ప్} + **న్ / మ్** across a Sanskrit compound boundary → class nasal (అనునాసిక సంధి) or class media (doublets సన్మార్గ/సద్మార్గ, వాఙ్నియమ/వాగ్నియమ, దృఙ్మధు/దృగ్మధు). Three alternative resolutions at the junction:
  - **Option A** the substituted nasal (న↔గూఢపాన్మద[న]; నా↔సన్మార్గ; ండ↔ఉన్మాదుల్[నా] via anunāsika);
  - **Option B** the pre-sandhi stop (ద↔గోత్రభిన్మణి[త] vargaja; గ↔దృఙ్మధు[క]; ధా↔హృన్మధ్య[త]; తే↔సరిన్నికట[తి]);
  - **Option C** the second word's initial న/మ by saṁyukta (న↔వాజ్నైపుణ[నై]; మ↔ఋఙ్మంత్ర[మ]; మా↔మన్మందిరము[మ]).
  status: canonical (kind: vidhāna).
- **YATI-SP-05.1** [6.35.5] **-మయ(ట్) / -మాత్ర(చ్) suffixes** (చిన్మయ, తన్మాత్ర): sandhi is obligatory (no *చిద్మయ), so **Option B is barred**; only A (న) or C (మ). status: mandatory.

## F. ప్రత్యేక యతి [6.36 – 6.36.4]

- **YATI-SP-06** [6.36] When the demonstrative **అది / అవి** fuses with an oblique base and its initial అ **elides** (వృత్తిలోపము, Bāla Vyākaraṇam Sandhi 45: చేతిది, నాది, నీది, దానిది, అట్టిది, మంచిది), yati at that site is **strictly a consonant yati on the surface** (ది↔చేతిది[తి]; దానిది[ని]↔నీ; అట్టిది[టి]↔ఘటించిన[టి]); the elided అ is extinguished and cannot be matched. status: mandatory (kind: vidhāna).
- **YATI-SP-06.1** The unelided hiatus form (చేతియది, నాయది) resolves normally: య్+అది → అ via స్వరప్రధాన (or సరస). status: canonical.
- **YATI-SP-06.2** [6.36.4] **ఉన్నది / ఉన్నవి** etc. are అత్వసంధి, not ప్రత్యేక; they fall under దేశ్య నిత్యసమాస ubhaya (`YATI-UB-16`). status: canonical.

## G. ఏకతర యతులు / ఎక్కటి యతి [6.37 – 6.37.2]

- **YATI-SP-07** [6.37] **ర ↔ ర only** (సాధురేఫ) and **ఱ ↔ ఱ only** (శకటరేఫ); ర ≠ ఱ; neither pairs with any other consonant (ర pairs with the *vowel* ఋ under `YATI-SV-05` only). Vowel classes apply within each series. Nannaya's first verse (Ādi 1-3) uses రా↔రా thrice. status: canonical (kind: bhēda) — for ర↔ఱ see `YATI-SP-08`.

## H. ద్విరేఫ యతి / ఱవడి [6.38 – 6.38.3]

- **YATI-SP-08** [6.38] **ర ↔ ఱ**: prohibited by Appakavi, Nannaya, Tikkana, Errana, Śrīnātha (prāsa-vairamu / yati-bhaṅgamu); accepted by later poets and codified in Sulakṣaṇasāramu 2-164 (ఱవడి / ద్విరేఫయతి). Vowel classes must align (ర↔ఱ, రి↔ఱి, రు↔ఱు). Engine policy: strict/early mode → defect; late/prabandha/modern mode → valid. **Project decision (as for prāsa)**: printed corpora do not distinguish ర/ఱ reliably, so treat as an `orthographic_relaxation` accepted from the relaxed profile on. status: orthographic_relaxation.
- **YATI-SP-08.1** [6.38.1] **Doublet check first**: many stems exist in both forms (రాయి/ఱాయి, పాఱు/పారు, రంతు/ఱంతు, చెఱఁగు/చెరఁగు, ఊఱుఁగాయ/ఊరుఁగాయ, రెప్ప/ఱెప్ప, రేకు/ఱేకు, రొమ్ము/ఱొమ్ము, రేవు/ఱేవు); a line pairing ర with such a word may scan as ఏకతర via the doublet rather than as ద్విరేఫ. status: canonical (procedure).
- **YATI-SP-08.2** [6.38.2] Definite ద్విరేఫ (no doublet: క్రమ్మఱు, అంకు, గుఱ్ఱము, మీఱు, మాఱట): ర↔ఱ, రా↔ఱ, రి↔ఱి, రి↔ఱే, ఱి↔రే, రు↔ఱు, రూ↔ఱు, రో↔ఱు attested (Peddana, Pōtana, Kṛṣṇadēvarāya, Tikkana). status: orthographic_relaxation.
- **YATI-SP-08.3** [6.38.3] Extension: ఋ / C+ృ ↔ ఱి ఱీ ఱె ఱే (`YATI-SV-05.5`). status: orthographic_relaxation.

# 04 — Saṁyukta yati and the line-bridge fusions [6.26 – 6.30]

Source: `../yathi.md` parts 7–8. Overlaps `../yathi2.md` Y2.2, Y12.2.

## A. The conjunct axiom [6.26 – 6.26.4]

- **YATI-SY-01** [6.26] **సంయుక్త యతి** is a *procedure* (vidhāna), not a phonetic class. For a conjunct akshara C1+C2+…+V, the caesura is satisfied if **any single constituent consonant + the terminal vowel** matches the other coordinate; the poet never has to match all consonants. Example శ్రీ: as శీ (ūṣma/sarasa: ↔చె) or as రీ (ēkatara: ↔రి). status: canonical (kind: vidhāna).
- **YATI-SY-02** [6.26.2] Both **శబ్దసిద్ధ** clusters (శ్రీ, వ్రత, న్యాయ) and **సంధిగత** clusters (త్రిజగత్+విఖ్యాత → ద్వి; హృత్+వన → ద్వ) are decomposed identically. status: canonical.
- **YATI-SY-03** [6.26.3] **ద్విత్వాక్షర**: a geminate C+C+V is a conjunct of identical consonants → extract the single consonant and apply its class (త్త[త]↔థా vargaja; ట్టి[టి]↔ఠీ). status: canonical.
- **YATI-SY-04** [6.26.4] Saṁyukta yati only *extracts* the active consonant; the phonetic rule then applied (ప్రాణి, వర్గజ, సరస, ఊష్మ, బిందు …) is determined by that consonant's class. Attested across all 16 consonant classes in 6.27.1–6.27.16. status: canonical.

## B. క్ష [6.26.5]

- **YATI-SY-05** [6.26.5] **క్ష = క్+ష్+V** has the widest range of any Telugu consonant: Path A extract క → ప్రాణి {క}, వర్గజ {ఖ గ ఘ}, సరస-4 {చ ౘ ఛ జ ౙ ఝ}; Path B extract ష → ప్రాణి {ష}, ఊష్మ {శ స}, సరస-4 palatals. Attested: క్ష↔కా, గా, గ, ఖా, కృ, గృ, కీ, కో, గో, ఖ; క్ష↔చ్ఛ, ష, స, శా, జె, ఝ, శ, జ, చె, స్థు. status: canonical.

## C. Both coordinates conjunct; three-consonant clusters [6.26.6 – 6.26.7]

- **YATI-SY-06** [6.26.6] **ఉభయ సంయుక్తాక్షర యతి**: when both the వళి and the yati akshara are clusters, test **all pairings** C1A/C1B × C2A/C2B; any one hit validates (క్ష[క]↔ఖ్యా[ఖ]; ర్బీ[రీ]↔శ్రీ[రీ]; ష్టి[టి]↔డ్కిం[డి]; క్రీ[రీ]↔శ్రీ[రీ]); geminate vs conjunct likewise (త్త[త]↔ద్వై[దై]). status: canonical.
- **YATI-SY-07** [6.26.7] **Three-consonant clusters** C1+C2+C3+V keep full multi-path resolution over all three (క్ష్మా: కా↔గా, షా↔స, మా↔ంప in Appakavi 3-109; క్ష్మీ[కీ]↔కి, క్ష్వా[వా]↔వం, ర్త్యు[తు]↔దూ, త్ప్ర[ప]↔ర్బ[బ]). status: canonical.

## D. నకార సంశ్లేషము — drutam fusion across the line break [6.28]

- **YATI-SY-08** [6.28] When the preceding line ends in an inflected **ద్రుతము న్**, classical continuous orthography fuses it with the first consonant of the next line: న్+సా = **న్సా**. The వళి is therefore the cluster న్సా, and by `YATI-SY-01` its **న + V** may serve the yati (Manu Caritra 1-55: న్సా[నా]↔న్య[న]). Uncodified but universal (Nannaya Ādi 6-200; Tikkana; Errana). status: canonical (kind: vidhāna).
- **YATI-SY-08.1** [6.28(1)] Metric integrity: fusing keeps the previous line's final syllable guru, so gaṇa counts are unchanged; modern prints separate the న్ only for readability. status: informational.
- **YATI-SY-08.2** [6.28(4)] **Permissive, never mandatory**: if the line satisfies yati natively on its own initial consonant, the preceding drutam is ignored. status: canonical.
- **YATI-SY-08.3** [6.28.1] **Site 1 — line start**: న్+గ→న↔న; న్+ఘో→నో↔ంతు; న్+పా→నా↔ణ; న్+మ→న↔ంథా; న్+వ→న↔ంద; న్+సై→నై↔న; న్+హ→న↔న, etc. (the extracted న may then use ప్రాణి, బిందు, న–ణ, అనునాసిక). status: canonical.
- **YATI-SY-08.4** [6.28.2] **Site 2 — caesura site**: an internal న్ immediately before the yati akshara fuses with it (పయిపయిన్+మధ్యాహ్నము → న్మ[న] ↔ line-start ంద; గలిగినన్+భిక్ష → న్భి[ని] ↔ నీ; నా↔న్ర[న]; ణ↔న్వి[ని]). status: canonical.
- **YATI-SY-08.5** [6.28(10), 6.28.3] **Site 3 — dual fusion**: both coordinates fuse (…శోభిల్లుచున్ / మణి… ↔ …స్ఫురణమున్ సంశోభి → న్మ[న]↔న్సం[న]; న్ఖ[న]↔న్గ[న]; న్ము[ను]↔న్గో[నో]; న్మృ[నృ]↔న్వే[నే]; న్హృ[నృ]↔న్ని[ని]). status: canonical.
- **YATI-SY-08.6** [6.28(11)] The four-step verification order (native → site 1 → site 2 → site 3 → fail) is `YATI-EP-04`. status: canonical.

## E. లకార సంశ్లేషము — pollu-ల fusion [6.29]

- **YATI-SY-09** [6.29] Word-final uncombined **లు** optionally drops its ఉ (Bāla Vyākaraṇam Prakīrṇaka 16) → **ల్**, from the plural suffix (రాముల్, వనముల్) or a lexical root (కాల్, మొగుల్, ఒడల్). A line-final ల్ fuses with the next line's first consonant (ల్+గీ = ల్గీ) and the constituent **ల + V** may serve the yati (Tikkana, Virāṭa 2-55: ల్గీ[లీ]↔లీ). status: canonical (kind: vidhāna).
- **YATI-SY-09.1** [6.29.1] Site 1 line-start: ల్గ→ల↔లా; ల్గౌ→లౌ↔ళా (abhēda); ల్చూ→లూ↔లో; ల్ద→ల↔లా; ల్ప→ల↔ళం; ల్మ్రో→లో↔లుం, etc. status: canonical.
- **YATI-SY-09.2** [6.29.2] Site 2 caesura: ల↔ల్గా[లా], లు↔ల్ను[లు], లో↔ల్శు[లు], ళ↔ల్సం[ల]. status: canonical.
- **YATI-SY-09.3** [6.29.3] Site 3 dual: ల్గ[ల]↔ల్సా[లా]; ల్మే[లే]↔ల్హే[లే]. status: canonical.
- **YATI-SY-09.4** [6.29.4] Lexical-root లు (ఒడల్→ల్తి[లి]↔ల్తే[లే]; మొగుల్→ల్బ[ల]↔ల) behaves identically. status: canonical.
- **YATI-SY-09.5** [6.29] Optional (ఐచ్ఛికము): ignored when the line aligns natively (Śṛṅgāra Śākuntalamu 5-37). status: canonical.
- **YATI-SY-10** [6.29.5] న-saṁślēṣa and ల-saṁślēṣa may be used in different lines of the same stanza (line independence). status: informational.

## F. బహుయతి నియతి [6.30 – 6.30.4]

- **YATI-SY-11** `=Y2.2` [6.30] In multi-yati lines (`YATI-POS-12`), when the వళి is a conjunct, **the constituent chosen for the first caesura must be kept for every later caesura of that line**. Appakavi 3-112 (విజయభద్ర రగడ): line 1 క్ష్మా → కా↔క, కా↔ఘ, కా↔గా (compliant); line 2 క్ష్మా → కా↔కం, then షా↔సం, then మా↔మ — each pair valid but the line commits **నియతిభంగము**. status: mandatory (kind: vidhāna).
- **YATI-SY-11.1** [6.30.1] If an *internal* coordinate is a cluster, the consonant that matched the opening fixes the chain; later coordinates cannot switch to that cluster's unused members (Appakavi 3-114). status: mandatory.
- **YATI-SY-11.2** [6.30.2] **సీసము exempt** ("సీస పదములఁ దక్కన్", Appakavi 3-110): halves (gaṇas 1–4 / 5–8) are independent domains; C1 in one half, C2 in the other is no violation. status: canonical.
- **YATI-SY-11.3** [6.30.3] Adherence corpus: స్రగ్ధర ధ్వాం[ధా]↔త్త[త]↔ద; శ్రీ[శీ]↔స్మి↔స్ఫీ; శ్రీ[రీ]↔ర్చి↔శ్రే (Bhāgavatam 1-1); మహాస్రగ్ధర స్ఫు[పు]↔ద్భు↔స్ఫూ; తరువోజ స్రు[సు]↔శూ↔సొం↔సొ. status: informational.
- **YATI-SY-11.4** [6.30.4] Rare switches (Amuktamālyada 6-135, 4-238; Bhāskara Rāmāyaṇamu 2-185) are కవిప్రామాదికము → flag as non-canonical. status: deprecated.

# 09 — Rejected, restricted and dissolved yatis

Source: `../yathi.md` parts 3, 9, 11, 16–20. Each bullet names a pairing or procedure the engine must **refuse** (status `forbidden`), accept only in the historical profile for identification (`deprecated`), or treat as no rule at all (`informational`). Cross-references point to the positive rule that the rejection guards.

## A. Procedural rejections

- **YATI-RJ-01** `=Y10.6` [6.3.11, 6.78] **అఖండ యతి**: matching the fused *surface consonant* across a transparent vowel-sandhi junction instead of the second word's vowel (వేదార్థ → దా instead of అ; పరమేశ్వర → మే instead of ఈ; చతురోక్తి → రో instead of ఉ; కవీంద్ర → వీ instead of ఇ; నీవారోహింపుము → వా instead of ఆ; తెలుపుచుండ చు–సొ). Appakavi rejects it outright; later collections (Sukavi Manōrañjanamu) of sporadic attestations are scribal corruptions, poets' slips (స్థాలిత్యము) or misclassified నిత్యసమాసములు. Engine: mandate svara-pradhāna (`YATI-SV-02`) on all transparent junctions; flag akhaṇḍa as a defect. status: forbidden (identify as deprecated in the historical profile).
- **YATI-RJ-02** [6.15.4] **False transitivity**: never derive a bridge from two sanctioned bridges (ఇ↔ఋ + ఋ↔రి ⇏ ఇ↔రి). Only explicitly attested/sanctioned bridges exist (the sole sanctioned composition is బిందు∘న–ణ = అనునాసికాక్షర, `YATI-VY-05`). status: mandatory.
- **YATI-RJ-03** [6.5.3, 6.6.1, 6.7.1] **Vowel detachment** from a host consonant is illegal for every vowel except ఋ: అ–క, ఇ–కి, ఉ–కు, కి–ఇ are not yatis; క≠ప, కి≠పి though both carry the same vowel. status: mandatory.
- **YATI-RJ-04** [6.2.1] **Cross-class vowels** (అ–ఇ, ఇ–ఉ, ఏ–ఆ …) never pair, whatever the consonants do. status: mandatory.

## B. Rejected consonant pairings

- **YATI-RJ-05** [6.62, Appakavi 3-262] **Plain వర్గాంత్య yati** (బిందురహిత వర్గపంచమాక్షర యతి): stops 1–4 with their class nasal *without* a preceding anusvāra (త–న, థ–న, ద–న, ధ–న, ప–మ). Interpolations in Kavijanāśrayamu claiming this are spurious. Guards `YATI-VY-02.2`, `YATI-VY-03`. status: forbidden.
- **YATI-RJ-06** [Appakavi 3-266] **య-శ వర్గద్వయ యతి** (Sulakṣaṇasāramu): mutual matching inside {య ర ల వ} and inside {శ ష స హ} (య–ర, య–ల, య–వ, ర–వ, ల–వ, శ–హ, ష–హ, స–హ) — hētu-rahita; only ర–ల (`YATI-DL-02`) is independently established. status: forbidden.
- **YATI-RJ-07** [Appakavi 3-268] **సంభావన వడి / మ–వ యతి** (Lakṣaṇa Dīpikā, Lakṣaṇa Rājīyamu): direct మ ↔ వ by false transitivity through the labial stops; invalid in every vowel class (మ/మా≠వ/వా, మి≠వి). Only the `U`-class nexus ము–వు survives (`YATI-DL-06`). status: forbidden.
- **YATI-RJ-08** **ఉ–వు యతి**: independent ఉ ఊ ఒ ఓ with వు వూ వొ వో (folk ఊరు/వూరు confusion); వు never word-initial in classical writing. status: forbidden.
- **YATI-RJ-09** **ఉ–ఋ యతి**: `U`-class syllables (కు, బు, బొ, ము, భూ) with ృ syllables (కృ, బృ, మృ) — ఋ is `I` class; spoken ఋ≈రు is the confusion. status: forbidden.
- **YATI-RJ-10** **ఋ–రు యతి**: ఋ / C+ృ with రు రూ (త్రు, గ్రూ) — ఋ pairs only with రి రీ రె రే (`YATI-SV-05`). status: forbidden.
- **YATI-RJ-11** **ఘఞ్ యతి** (Ānanda Raṅgarāṭchandamu 3-232–237): ubhaya on లా of ఆలాప (ఆ+లప్+ఘఞ్) — the length is ādi-vṛddhi, not sandhi (no *ఆల+అప); would absurdly license ubhaya on పాక, పాద. లా matches only as ల (prāṇi). status: forbidden (vowel track).
- **YATI-RJ-12** [6.55] **ఋ–లి** (Gōpīnātha Rāmāyaṇamu లి↔వృ): pseudo-deduction from ఋ↔రి and రి↔లి. status: forbidden.
- **YATI-RJ-13** [6.58] **ల–ఢ, ళ–ఢ**: no phonetic equivalence, no attestation (Appakavi: అగ్రాహ్య). status: forbidden.
- **YATI-RJ-14** [6.59] **ధ–డ, ద–ఢ, త–డ**: only ద–డ interchanges (`YATI-DL-05`). status: forbidden.
- **YATI-RJ-15** [6.37, 6.38] **ర–ఱ in strict (Nannaya/Tikkana/Appakavi) mode** is యతిభంగము; in relaxed/late mode it is `YATI-SP-08`. status: forbidden in profile strict; orthographic_relaxation from relaxed.
- **YATI-RJ-16** [6.53] Pairs **not admissible in prāsa yati**: ద–ధ, డ–ఢ, ల–డ, ళ–డ, స–ష; variants సంయుక్తాసంయుత and పూర్ణార్ధబిందు (`YATI-PY-26/27/28`). status: forbidden / deprecated.

## C. Rejected ubhaya / morphological claims

- **YATI-RJ-17** [6.45, Appakavi 3-239–240] **పంచమీ విభక్తి యతి**: splitting కంటెన్ / కన్నన్ as కి+అంటెన్ / అన్నన్ to license ubhaya on క. కన్న is not a vibhakti; the split is ungrammatical; the one Camatkāra Rāmāyaṇamu instance is kavi-prāmādikamu. క scans as hal only. status: forbidden (vowel track).
- **YATI-RJ-18** [6.48] **క్యచ్ denominatives** (-ఆయిత …): vowel track illegal (`YATI-UB-14`). status: forbidden (vowel track).
- **YATI-RJ-19** [6.36] **ప్రత్యేక** elided అది/అవి (చేతిది, నాది): vowel అ cannot be reached (`YATI-SP-06`). status: forbidden (vowel track).
- **YATI-RJ-20** [6.47] **Prādi on హలాది roots** (ప్రమాణ, అనురాగ, సుమహత్, నిస్తరించి), on the prefix head (ని of నిరతిశయ), or with ఆఙ్ (ఆకలిత): no ubhaya (`YATI-UB-10.1/10.2/10.4`). status: forbidden (ubhaya).
- **YATI-RJ-21** [6.48, 6.49] **Ubhaya on ordinary junctions**: నఞ్ + consonant (అభావ), Telugu ఉత్వసంధి with a prefix (అతఁడధిపతి), non-అది/అవి అత్వసంధి (ఉన్నపుడు, విన్నంత), numerals without internal sandhi (ఒకడు), స- + consonant stem (సకుటుంబ), పదార్థ = "word-meaning", నిశాంత = "dawn": svara-pradhāna only or no node (`YATI-UB-11.2/11.3`, `YATI-UB-13`, `YATI-UB-15`, `YATI-UB-16.1`). status: forbidden (hal track).
- **YATI-RJ-22** [6.35.5] **Vikalpa Option B on -మయ/-మాత్ర stems** (చిన్మయ, తన్మాత్ర): pre-sandhi stop unreachable (`YATI-SP-05.1`). status: forbidden.
- **YATI-RJ-23** [6.75, 6.76] **Augment consonants** (టుగాగమ ట, నుగాగమ న, ఆరగాగమ ర/ల, ద్విరుక్త ట్ట) on the hal track (`YATI-DL-10/11`). status: forbidden (hal track).
- **YATI-RJ-24** [6.66, 6.77] **Clitic / suffix vowels** on the svara track: ఏవార్థక అ/ఎ/ఏ, verbal -ఎడు/-ఎడి (`YATI-DL-08/12`, `YATI-UB-04.1`). status: forbidden (svara track).
- **YATI-RJ-25** [6.30.4] **బహుయతి నియతిభంగము** (switching cluster constituents between caesuras) is a defect; sporadic classical lapses are kavi-prāmādikamu (`YATI-SY-11`). status: deprecated.
- **YATI-RJ-26** [6.4.7] **గూఢస్వర on ఓ before a voiced consonant** (యశోనాశ → hidden అ): there is no hidden vowel (`YATI-SV-04.3`). status: forbidden (svara track).
- **YATI-RJ-27** [6.17.1] **Sarasa అ–య on an āgama య** (వినియల్గి): bypass to svara-pradhāna instead (`YATI-VY-09.1`). status: forbidden (as sarasa; the line still passes as svara).

## D. Pseudo-classes the book dissolves (no new matching logic)

- **YATI-RJ-28** [Chandodarpaṇamu 1-115] **రేఫయుత యతి**: an orthographic disambiguation — pure Telugu (అచ్చతెనుఁగు) roots contain no vocalic ఋ; a [ru] sound in native roots (మ్రుచ్చిమి, స్రుక్కండు, క్రుమ్ము) is ర్+ఉ, to be processed by saṁyukta/ēkatara on ర (or మ/స/క), **never** by ఋ-yati. status: informational (normalisation rule).
- **YATI-RJ-29** [Sulakṣaṇasāramu] **సౌభాగ్య యతి**: merely the coincidence of two ubhaya nodes (two prādi or two nitya-samāsa tokens) at the వళి and the yati site; not a distinct class. status: informational.
- **YATI-RJ-30** [Bāla Vyākaraṇamu Prakīrṇaka 3] **యా-యతి**: native nominals admit యె/యే only in ఊయేల, పయ్యెద, తాయెతు (and variants ఉయ్యెల, పయ్యద, తాయెత్తు); in verbs it is regular (కనియెన్, వినియెన్, పోయెన్). The "rule" only reminds the parser to check whether the poet scanned యె (`I` vowels / semivowel) or the historical య (`A`). status: informational.
- **YATI-RJ-31** [pre-Appakavi] **ఎక్కటి యతులు**: the old isolation class {మ ర ఱ ల వ} is obsolete — మ pairs via బిందు, మవర్ణ, ము-kāra/ము-వు; ర–ఱ in late usage; ల with ళ and డ; వ with బ ప ఫ భ. Only ఏకతర (`YATI-SP-07`) survives for ర and ఱ individually. status: informational.
